Checks the markup handed to patchElements and its kin: unclosed or stray tags, text outside elements, a missing id on a top-level element when no selector is given, a mode that needs a selector, a blank selector, and </script inside a script body.

A literal argument core refuses as the call runs is flagged in core's own words: an empty eventId, a retry of no time or less, signals that are not one JSON object, a blank script, a javascript: redirect, elements that are only white space, and a selector a response header cannot carry. A value the code computes is left alone.
