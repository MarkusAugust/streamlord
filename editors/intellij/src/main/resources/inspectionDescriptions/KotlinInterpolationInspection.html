Reports a Kotlin string template where a Datastar signal was meant: "$count++" becomes "++" at runtime, and the browser never sees a signal.

In a Datastar expression handed to the DSL this is an error. Inside an HTML string a template in a data-* expression is a warning, since a server value there works as often as it is the trap; in element text it is a hint, since there it is usually meant.

Quick fixes: the DSL helper (increment("count"), signal("count"), toggle("open")), a $$"..." literal (Kotlin 2.2+) where a single dollar is text, or the ${'$'}count escape.
